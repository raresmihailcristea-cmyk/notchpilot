# NotchPilot — Hardware Command Center for macOS Notch

![NotchPilot macOS](https://raw.githubusercontent.com/raresmihailcristea-cmyk/notchpilot/main/assets/banner.png)

> **Supercharge your MacBook Notch into a sleek, real-time command center.**  
> Monitor CPU, RAM, disk, network, and battery with Liquid Glass cyber aesthetics.

---

## 🌟 Overview

**NotchPilot** is a native macOS application engineered specifically for Apple Silicon (M1, M2, M3, M4) and Intel Macs running macOS 14.0 Sonoma or later. It transforms the physical camera cutout of MacBook Pro and MacBook Air into a live, interactive hardware telemetry HUD.

On external displays and notch-less Macs, NotchPilot seamlessly anchors to the top-center bezel or transforms into a free-floating desktop instrument panel.

---

## 🚀 Key Features

* **Camera Cutout Hugging**: Flawlessly hugs the physical notch of MacBook Pro and MacBook Air displays.
* **Liquid Glass & Cyber Aesthetic**: Translucent `.ultraThinMaterial`, glowing neon accent rings, specular highlights, and an active resting EKG heartbeat pulse.
* **Full Hardware Telemetry**:
  * **CPU Utilization**: Live processor load across performance and efficiency cores.
  * **RAM Footprint**: Real-time memory allocation (GB) and percentage.
  * **Disk Volumes**: Live free space monitoring on primary storage.
  * **Network Bandwidth**: Instantaneous download and upload throughput meters.
  * **Battery & Power**: Health percentage, charging indicator, and time-to-full/empty telemetry.
* **Top Consumer Process Drawer**: Live drawer revealing the top CPU and memory-intensive apps without opening Activity Monitor.
* **Thermal Pressure & Metal GPU Profile**: Real-time thermal headroom monitoring (Nominal, Fair, Serious, Critical) to detect throttling early.
* **Free Drag & Reposition**: Grab the central grip handle and float the HUD anywhere on screen, with a single-click "Reset to Notch" snap magnet.
* **100% Offline & Private**: Zero cloud dependencies, zero data collection, zero network telemetry. Idles at under 0.8% CPU.
